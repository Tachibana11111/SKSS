# 新幹線を運転 · Drive Shinkansen · Lái Shinkansen

[Tiếng Việt](README.md) · [English](README.en.md) · **日本語**

JR 5社が運行する新幹線を運転するゲームです。ブラウザだけで動作します(HTML/JS、インストール不要)。

![東海道線を走るN700Sのぞみの運転台](docs/screenshots/cab.jpg)

</div>

趣味のプロジェクトであり、**非公式で、JRおよび文中に登場するいかなる会社とも関係ありません**。名称、車両形式、駅名は実在のものですが、シミュレーションのためだけに使用しています。

**遊ぶ:** このリポジトリのGitHub Pages(*Settings → Pages* を参照)、またはローカルで実行(「ローカルで実行」を参照)。表示言語は **English、日本語、Tiếng Việt** から設定画面で選べます(初期値はブラウザの言語に従います)。

## 特長
- **7路線、JR 5社:** 東海道・山陽・九州、東北・北海道、上越、北陸、西九州、さらにミニ新幹線の山形・秋田(東京・福島・盛岡での併結・分割も再現)。**2026年10月の実際のダイヤ**に基づき、N700/N700S、E5、E6、E7/W7、E8、H5、800、N700S-8000から、検測車の923形ドクターイエロー、E926形East iまで登場します。
- **本格的な運転:** 力行13段、ブレーキ8段、ATC、定速運転、パンタグラフ、ワイパー、前照灯、周波数切り替えのデッドセクション、駅の待避線と通過線、駅構内への分岐器、実ダイヤどおりの先行列車と通過列車。
- **天候とランダムなトラブル(シード指定):** 雨、雪、台風、地震、トンネル内の火災、急病人、動物、踏切での立ち往生、復唱が必要な運転指令、快速列車の追い越しのための臨時停車。難易度は4段階。
- **多彩な視点:** 擬似3Dの運転台、2D横視点、真上から見るミニマップ(北が上)、左右の客室窓、最後尾カメラ。
- **全国マップ**([スクリーンショット](#スクリーンショット)): 47都道府県と、**データにあるすべての島**(北方領土は点線で描画)、Wikipediaの色による10の路線区間、**実ダイヤで走るすべての列車**と天候・地震。駅や列車をクリックすると詳細(前後の列車と間隔を含む)を表示します。
- **車内放送**(日本語または英語、字幕付き): 次の停車駅、乗り換え路線、ドアが開く側、遅れ、トラブルをお知らせします。
- **運転を学ぶ:** 4つのステップ式レッスン(運転と停車、機器、トラブル、パンタグラフとATC)。**プロフィール:** 実績14種、ベスト記録、履歴、過去の運行のリプレイ。
- **サウンド:** 走行音、風、雨、警笛、駅の環境音、旅客機の機内音(J)、メニューの**ミュージックプレーヤー**(新幹線の駅メロディ21曲)。
- **多言語対応:** English、日本語(駅名は漢字、列車名は「のぞみ1号」形式)、Tiếng Việt。
- 風景はOpenStreetMapのデータから生成しています。調査ノートは [`docs/`](docs/00-progress.md)(ベトナム語)、ゲーム設計は [`docs/10-thiet-ke-game.md`](docs/10-thiet-ke-game.md) にあります。

## メニュー
- **ホーム画面:** 運転 · 運転を学ぶ · プロフィール · 設定 · 素材のクレジット(JR 5社のロゴも表示。クリックで各社の公式サイトを開きます)。
- **運行の設定:** 路線、方向、列車、出発駅・到着駅、難易度、天候、シード、支線列車の併結。同じシードなら同じ運行になります。
- **一時停止(P または Esc):** 再開 · 設定 · プロフィール · スナップショット(F9) · やり直す · メインメニューへ。
- **設定:** 言語、車内放送(日本語/英語+字幕、字幕のみ、オフ)、風景(フル/軽量)、無線連絡で等速に戻す、そして**キーボードショートカット一覧**。
- **ミュージックプレーヤー**(左下、メニューのみ): 再生/一時停止、前へ/次へ、全曲リピート・1曲リピート・シャッフルを切り替える1つのボタン、曲リスト、ミュートと音量、進行バー、折りたたみ。YouTubeの埋め込みプレーヤーで再生します(通信が必要。最初のクリックまたはキー入力で自動再生を開始)。

## 操作
一覧は **設定 → ショートカット** にあります。

| キー | 操作 |
|---|---|
| W / S | 加速レバーを上げる / 下げる(13段) |
| ↓ / ↑ | ブレーキを強める / 弱める(0に戻してから再び加速可能) |
| Space · Q | Nに戻す · 非常ブレーキ |
| Enter | ドアを閉める。ランプが点灯したらレバーを引いて発車 |
| C · [ ] | 定速運転 · ∓5 km/h調整 |
| A · G · V · L | ATC(2回押すと切) · パンタグラフ · ワイパー · 前照灯 |
| Y / N · M | 指令の復唱、受諾 / 拒否 · 安心させる放送 |
| X · K | (検測車)測定オン · 不具合をマーク |
| Tab · B · O | 視点切り替え · 最後尾カメラ · 無線の非表示 |
| , · . | 左 · 右の客室窓(もう一度押すと運転台に戻る) |
| J | 機内音のオン/オフ(右上のスピーカーボタン:1回押すと音量バー、2回目でミュート) |
| D | 全国マップと現在の視点を入れ替え(ホイールでズーム、ドラッグで移動、駅・列車をクリックで詳細。現在地ボタンで自列車に戻る) |
| H | 警笛(作業員、シカ、通過駅、踏切、前方の停止列車では自動でも鳴ります) |
| P(または Esc) · F9 · F11 | 一時停止 · スナップショット(PNGと場面を再現するJSON) · 全画面 |
| 1 2 3 · T · R | 倍速 ×1/×4/×16(右上の四角い ×N ボタンで ×1 → ×4 → ×16 と切り替え) · 自動運転 · やり直し |

## ローカルで実行
```
cd prototype/drive
python -m http.server            # その後 http://localhost:8000 を開く
```
`index.html` を直接開いても動きますが、駅の環境音はシークできず、ミュージックプレーヤーには `http://` のアドレスが必要です。

## テストとデプロイ
```
node tests/run.js                # シミュレーション、マップ、多言語などのテスト(約5分)
node tests/run.js --time         # 各セクションの所要時間を表示
node tests/run.js --shard=1/4    # 4分割のうち1番目のみ実行(並列実行用)
```
GitHub Actions: `ci.yml` はプッシュごとにテストを実行し、`pages.yml` はテスト後に `prototype/drive` をGitHub Pagesに公開します。技術メモ(ファイル構成、多言語、マップ、音楽)は [`prototype/README.md`](prototype/README.md)(ベトナム語)を参照してください。
