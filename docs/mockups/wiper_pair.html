Mockup: bộ gạt mưa đôi (nở ra / co lại)

Hai trục đặt ở HAI BÊN đáy kính (đối xứng qua giữa), mỗi cần quay như cần hiện tại (±Θ quanh phương thẳng đứng) nhưng hai cần quay NGƯỢC chiều nhau. Co lại: cả hai cần ngả vào trong hết cỡ, hai lưỡi gạt thẳng đứng song song ở chính giữa. Nở ra: cả hai ngả ra ngoài hết cỡ, tầm quét mỗi bên rộng gấp đôi cần đơn. Khoảng cách trục tự tính để lúc co lại hai lưỡi đúng giữa: P = L·sinΘ + khe.

Cách tính: θ(t) = Θ·cos ωt (+Θ = co lại, −Θ = nở hết). Lưỡi trái ở x = c − P + L·sinθ, lưỡi phải ở x = c + P − L·sinθ, y = đáy − L·cosθ; P = L·sinΘ + g (g = nửa khe lúc co). Tầm quét: từ c − P − L·sinΘ tới c + P + L·sinΘ (mặc định ±372 px so với ±175 px của cần đơn).

  • Co lại: hai lưỡi cách nhau 2g (mặc định 44 px), song song ở giữa kính; nở hết: lưỡi ở ngoài cùng cách giữa P + L·sinΘ.
  • Cần đơn hiện tại giữ lại ở nút trên để so sánh.
